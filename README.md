## Backend configuration

Before running the .NET backend, configure these environment variables:

- `ConnectionStrings__DefaultConnection` with the SQL Server connection string.
- `JWT__Secret` with a securely generated signing key.

Do not commit connection strings, signing keys, or other credentials to the repository.
